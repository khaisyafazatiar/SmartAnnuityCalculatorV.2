# SmartAnnuityCalculatorV.2
Smart Annuity Calculator adalah aplikasi kalkulator anuitas berbasis web yang membantu pengguna menghitung cicilan, melihat tabel amortisasi, membandingkan tenor, dan melakukan simulasi perubahan pinjaman. Dilengkapi desain interaktif bertema Deep Ocean untuk menghadirkan pengalaman belajar matematika keuangan yang menarik dan mudah dipahami.
